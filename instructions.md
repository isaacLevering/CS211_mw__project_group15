# **How to Run These Programs:**

1.Right click on the bar in the top middle of the file explorer window and copy address.

2.open terminal

3.type cd (paste file address here)

4\. copy one of the following:

g++ -std=c++17 -Wall -Wextra -pedantic game2048/main.cpp -o game2048\_app

g++ -std=c++17 -Wall -Wextra -pedantic luhn/luhn.cpp -o luhn\_app



(the top text makes 2048, the bottom make Luhn)



These will make an app in the same file.



5\. Run the app

6\. Enjoy!
